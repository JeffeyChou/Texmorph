texmorphSeekable formula morphing

Animate one LaTeX formula into another. Every frame is a pure function of progress t, so you can drive it from a slider, a timeline or a video frame counter.

Get started
How it works
GitHub

No clock

The library never schedules frames. render(t) works in any order, so scrubbing, reversing and frame-by-frame video export just work.

Exact endpoints

At t = 0 and t = 1 the real formulas are shown, pixel-identical to a plain rendering.

KaTeX and MathJax

A pure planning core and a renderer-agnostic DOM driver. KaTeX for speed, MathJax SVG for coverage and cross-browser geometry.

Fits your stack

Adapters for GSAP timelines, a Web Component and Remotion videos, plus a script-tag build.
